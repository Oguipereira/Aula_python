# Aula Python

Este repositório reúne exercícios, anotações e pequenos projetos desenvolvidos durante minha jornada de aprendizado em Python.

O objetivo é documentar minha evolução na linguagem, explorando desde conceitos fundamentais de programação até aplicações mais práticas envolvendo automação, manipulação de dados, orientação a objetos e resolução de problemas.

Ao longo dos estudos, busquei transformar teoria em prática por meio de exercícios e desafios que contribuíram para o desenvolvimento do raciocínio lógico e da construção de uma base sólida em programação.

## Conteúdos Explorados

- Lógica de programação
- Variáveis e estruturas de controle
- Funções e modularização
- Estruturas de dados
- Programação orientada a objetos
- Manipulação de arquivos
- Tratamento de exceções
- Automação de tarefas
- Introdução à análise de dados

## Objetivo

Manter um histórico da minha evolução em Python e servir como ambiente de experimentação para novos conceitos, técnicas e soluções.

## Tecnologias

- Python
- Jupyter Notebook
- Google Colab
